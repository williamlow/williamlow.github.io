Groundtruth Agent Prototype

Private prototype for WhatsApp-based incident-reporting workflows.

Groundtruth Agent is a limited test prototype that explores how WhatsApp messages can be received, converted into structured draft incident records, and followed up with clarifying questions where key information is missing.

This prototype is for controlled testing only. It is not a public emergency reporting service, official alerting system, or operational response mechanism.
